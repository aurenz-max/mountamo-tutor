## Canonical path change (same day, user ruling)

Pip no longer waits for a tutor session. `PipSurfaceStore` activates surfaces from
events (first surface; then the surface whose pose last moved into a non-idle
phase; lesson focus and the tutor's active block are claims), `CuratorCompanion`
renders the actor with no session, `usePipSurface` publishes every commit with
change detection (no dependency lists), and `usePipTargets` replaces the per-primitive
element maps in all eight primitives. Classic primitives count speech only for their
own block.

- Vitest: 33 suites / 437 tests pass, including `PipSurfaceStore.test.ts` and the helper
  attach test rewritten to need no session. `typecheck:lumina` 0; tsc 770 = baseline.
- Drive, no sign-in: Number Sequencer shows Pip `idle` in its dock before Start and moves
  it to the new dock on regeneration; Comparison Builder tap → `look`. Skill-shipped
  script with `start;speak:3`: Sorting Station `point@focus[ring]`.
- Not driven: the lesson's scroll-focus claim (`ManifestOrderRenderer`) — should work,
