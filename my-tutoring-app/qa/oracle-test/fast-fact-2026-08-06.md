# Oracle Test — fast-fact — 2026-08-06

**Trigger:** a live lesson ("Super Counting Within 20") rendered `text-large: "7"` above
*"Which number is shown here?"* with options 6/7/8. The student pixel-matches the glyph to a
button; nothing is measured.

**Result: FAIL in all four subjects.** The leak is not a math bug — it is the primitive's
default behaviour wherever the generator reaches for a `text-large` visual.

## Oracle

`service/qa/oracles/fast-fact.ts`, registered in `CONTENT_ORACLES`. Coverage delta **47 → 48**.
Note `fast-fact` carries `supportsEvaluation: true` but **no `evalModes`** in the catalog, so it
is absent from the 133-primitive evaluable count and shows `inCatalog: false`. It is an L0
primitive that ships in real lessons anyway — runs use `evalMode=default`.

**Independence rule.** The oracle mirrors the *component's* grading predicate
(`FastFact.tsx isAnswerCorrect`) and applies it to every option, asserting exactly one passes.
It never reads the key's position — which matters because `reconstructChallenge` force-splices
`correctAnswer` into `options`, so a naive "is the key present" check could never fail.
For counting items it re-derives the answer outright by counting emoji grapheme clusters.

| Check | What it catches |
|---|---|
| `answer-leak` (visual identity) | the visual IS the answer — representation shift broken |
| `answer-leak` (stem) | prompt names/quotes the answer and no distractor |
| `answer-leak` (single option) | one-button challenge — the `reconstructChallenge` pathological branch |
| `answer-key-desync` (grading) | 0 or ≥2 options grade correct (incl. `acceptableAnswers` colliding with a distractor) |
| `answer-key-desync` (count) | emoji shown ≠ numeric key |
| `answer-key-desync` (sentinel) | the `'???'` fallback ships as the key |
| `schema` | duplicate options, empty prompt, drill too short to measure |
| `scope` | numeric answer above the topic ceiling |
| `clustering` | answer values repeat; correct button parked in one slot |

`uncheckedTypes`: `image-visual` (an oracle cannot see what an imageUrl depicts),
`emoji-count-without-alt` (no alt ⇒ cannot tell a depicted count from a derived one).

**Seeded-violation tests:** `__tests__/fast-fact.test.ts`, 25 tests, green. Every check class
proven to fire. Clean fixtures are real generations (history, science); `litLeaky` and `mathLive`
are **unmutated real output** that ships bugs.

### Representative findings (all verified true positives)

- **Science** — `text-large "Fe"` with key `Fe`, `"Hg"` with key `Hg`, `"O"` with key `O`.
  The same identity leak as the numeral bug. The PRD's own good example (`Fe` → **Iron**) is
  the shape that should have been generated.
- **Language Arts** — every item of one drill leaked: 7 via `text-large` showing the word,
  3 via prompts like `"Find the word: look"` and `"Find the word: 'is'"`.
- **Math** — `text-large "20"` with key `20`; plus `"What is the final number when counting to
  20?"` with key `20`. Also **position clustering**: the correct button sat in slot 1 in 8/10
  and 9/10 challenges — gameable without reading anything.
- **History** — `duplicate options: [New Mexico, Nevada, Arizona, Arizona]`, which also made
  **two buttons grade correct**. A React `key={opt}` collision and an ambiguous key at once.

### False positive found and fixed during the run

First live run flagged `"How many fingers make up two full hands?"` over 🖐️🖐️ (key 10) as a
count desync. That item is legitimate — the answer is *derived*, not depicted. The counting
check now only applies when the counted noun is attested in the visual's `alt` text
("How many **stars**" ← alt "15 **stars**"). Both directions are regression-tested.

## Root cause

Three layers, none holding:

1. **No code guard.** `reconstructChallenge` validates options and splices the key in, but never
   compares `visualContent` to `correctAnswer`.
2. **The rule is prose only**, and self-contradicting — `gemini-fast-fact.ts:401` says "NEVER
   reveal answers in ... visual content" while line 402 says to use `text-large` for "math
   expressions, symbols".
3. **The PRD models the leak.** `PRD-FastFact.md:298` ships `"Which word is 'the'?"` with
   `largeText: "the"` as a reference example.

The missing invariant is **representation shift**: the visual and the options must be different
representations of the fact. `Fe` → "Iron" ✅. `7` → `7`, `the` → `the` ❌.

**Standing caveat now that the guard exists:** this oracle's `answer-leak` checks have
become regression detectors for the generator guard rather than independent discoveries of
authoring quality. The two implementations are kept deliberately separate — no shared code —
so a bug in the guard still fails the oracle, but a green run no longer means the content
was *authored* well.
