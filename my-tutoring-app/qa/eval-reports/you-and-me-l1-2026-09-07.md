# You & Me — L1 eval modes, 2026-09-07

Two distinct spoken tasks are registered end to end. L0 `describe_action` behavior is retained.

| Mode | Task | β | a | Turns |
|---|---|---|---|---|
| describe_action | Produce I/you from the current named speaker's perspective | 2.5 | 1.6 | 6 |
| describe_independent_action | Express an action done without help using myself/yourself bound to the same actor as I/you | 3.5 | 1.6 | 6 |

These are design priors, not measured calibration. Both have pictorial support (scaffoldingMode 2); the additional subject/self binding constraint motivates the +1 β adjustment. Backend import checks confirmed both β values and a=1.6, c=0.

Independent-action mode targets guided emphatic/by-self usage from the design studio (LA004-04-J), not every grammatical use of reflexive objects. The visible and spoken scene states that no one helped. It asks for a self word but does not supply myself/yourself before an attempt. The judge contract requires consistent actor, subject and self referents, rejects token-presence matches and omission of the requested form, and accepts natural phrasing. Personal-pronoun mode never requires a self form.

## Implementation and limits

- Context-native registration already carries `targetEvalMode`, intent, objective and scope. `resolveEvalModes` now consumes them; every independently planned scene call has a narrowed root `type` enum. Modes are planned before generation, not filtered afterward.
- Three scenes for a single task; two per task for mixed/blend. Speaker-order diversity is enforced within each task. Complete fallback scenes retain the planned type and disclose built-in routines; a narrow custom theme is not guaranteed during fallback.
- Component uses each active challenge's type. Aggregate metrics identify mixed sessions honestly and retain mode-specific totals, correct counts and accuracy plus each turn's type/actor/speaker provenance.
- Support-tier inputs were tested for routing stability. Support withdrawal is the next skill layer; no easy/medium/hard behavioral distinction is claimed here.
- Browser/audio acceptance remains owed. Test both modes, mode transitions, fluent wrong bindings, correction/retry and final submission with a real microphone. Contract tests establish intended judge behavior, not actual live speech discrimination.
