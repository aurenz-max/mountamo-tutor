## What was built

- Route `app/api/lumina/observe-spoken-miss` (`observationRoute(spokenMissKind, …)`); the contract moved to
  `runtime/spokenMissContract.ts` with shared `offByMisses`, `numberMisses`, `spokenNumber`.
- `TeachingItem.misses?: KnownMiss[]`. `useTeachingWorkspace` posts the pending spoken answer with the item's list as
  soon as the learner's turn finishes (in parallel with the tutor's reply); a not-credited `apply_tutor_verdict`
  passes the reading onto `session.submit`. A reading not landed by the verdict is dropped, never attached later.
  The list never reaches the tutor packet. Trace stage `spoken_miss`, shown in the JEV inspector.
- Per family `<x>SpokenMisses(item)` beside `workspaceAssignment`, and the spoken ids in the catalog's
  `teachingWorkspace.misses`. Unit tables beside each function.
- Sweep: a stub route names the first listed miss; J8 fails an invalid list, an id missing from the catalog, or a
  not-credited answer that did not record it. `SPOKEN_MISS_OUT=<f>` dumps one request per item, with the journey's
  correct answer (`correctSaid`).
- Probe: `node scripts/spoken-miss-probe.mjs --requests <f>` runs any family's real requests: the correct answer and
  two non-answers must name nothing; each miss's examples must name it (or the first listed miss with that example).

## What the rollout learned

- State the scene fact before the learner's answer ("The group with fewer fish has 3. The learner's answer is 3 …").
  The per-miss check cannot see the screen; the bare claim failed it (0.62 < .7), fact-first passed 60/60.
- Letter names before `sounds_no_word`: otherwise every spelled word ("C, A, T") was named `sounds_no_word` (40/40).
- Short opposites (yes/no, push/pull) need "The right answer is X … The learner gives the opposite answer, Y".
- An explanatory clause at the end of a pattern weakens it; "The learner says "X" instead of Y" clears the gate.

## Findings (queued, not fixed here)

1. word-builder `root_only` ("play" for "playful") is never named: fit 0.36-0.68 over three wordings; the observer
   reads a clipped transcript as possibly the full word. Kept; never misnamed.
2. Levers: number-bond and place-value spoken ids are in the catalog `unanswered` list until M1's spoken slice decides
   which levers answer them. Phonics families whose levers already name these ids keep `unanswered` equal to the
   declared list because the lever tests pin it; the lever owner should prune it (handoff 22).
3. states-of-matter observe payload credits "Wax → gas", "Mercury → solid", "Chocolate → liquid": temperature-dependent
   keys, unchecked (`/eval-test states-of-matter observe`).
4. Sentence-shaped `expectedAnswer`s (addition-subtraction-scene, bar-model, knowledge-check, push-pull, the DI packs)
   are rubrics, not answers; the probe now takes correct cases from the journey instead.
5. Judgment calls kept, reversible in one list each: bar-model's comparison misses and spatial-scene describe_scene's
   `opposite_word` (bounded patterns inside an open reply; 0 false positives).
6. RP-2 unchanged: a coaching reply with no verdict still records nothing, so a named miss has no attempt to attach to.
