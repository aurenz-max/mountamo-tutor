# Spoken-answer misses: `spoken_miss` pilot (handoff 20 Part B, phase 1)

Date: 2026-09-27 · Text calls only (TypeSafe/JEV), no Gemini, no Live · Not wired into the runtime

## Result

A JEV observation kind names which of an item's known wrong answers a spoken answer is, with **0 false positives in 1,332 decisions under the final policy** (642 rescored offline from saved answers, 690 live): no correct answer, noisy or not, was named as a miss. The two math families are exact on the main set and on a held-out set of phrasings written after the policy was fixed. On letter-sound-link, the main set is exact and on the held-out set 12 of 87 known misses went unnamed. Every one of those errors leaves the miss unnamed; none names the wrong miss.

| Family (mode) | Known misses per item | Main set | Held-out set | False positives |
|---|---|---|---|---|
| counting-board (count) | `skipped_a_number`, `one_short`, `one_over`, `short_by_more`, `over_by_more` | 252/252 | 198/198 | 0 |
| ten-frame (subitize) | `empty_count`, `one_short`, `one_over`, `short_by_more`, `over_by_more` | 234/234 | 162/162 | 0 |
| letter-sound-link (see_hear) | `letter_name`, `keyword_word` (held sounds), `added_vowel` (held consonants), `other_sound` | 156/156 | 75/87 | 0 |

Three runs per case. Held-out misses by id: counting all 5 ids 18/18 to 36/36; ten-frame all 5 ids 18/18 to 21/21; letters `letter_name` 18/18, `added_vowel` 6/6, `other_sound` 15/18, `keyword_word` 3/12. Latency: median 165 ms, p95 about 230 ms, so the kind finishes well before the tutor's reply.

Sources for the cases: the W1 payloads (`counting-board.count`, `ten-frame.subitize`, `letter-sound-link.see_hear`) and each family's own `workspaceAssignment` (the task and expected answer are exactly what the runtime sends); harness `plainWrong`/`signatureWrong`; the liveJourneySpec wrong input (the digit walk one past); learner transcripts seen on saved Live audio runs ("Could it be 1 2 3 4 5?", "Okay, let's try it. 1 2 3 4 5 6", "ocho", "Let me try that again."); constructed noisy forms (homophones "for"/"ate"/"sicks", "It's 5:00.", Spanish, self-correction "five, no, four").

## What the pilot changed in the design

| Version | Shape | What failed |
|---|---|---|
| v1 | one Choice: the item's misses + `correct`/`other_wrong`/`no_answer` | Overlapping misses: the skipped walk "1 2 4 5" (also one over) named 0/18, empty-box count 7/18. Bare transcripts "s" and "p" named `letter_name`: 4 false positives. |
| v2 | generic correct/wrong/no-answer Choice + one Noul per miss, code applies list order | Math exact. Letters 101/156: "ess" read as near-correct, "mmm" read as filler. |
| v3 (final) | v1's Choice decides whether it is a known miss; per-miss Nouls and list order decide which | Final policy below. |

Final policy (`decideSpokenMiss`): a miss is named only when P(any known miss) from the Choice is at least 0.7 AND that miss's own Noul is at least 0.7; the first listed miss that clears the gate is named, so the domain's list order is the precedence. Either judgment alone named a bare "s" as the letter name (Choice .73, Noul .51) and "net" as the letter name `en` (Noul .59). The policy was fixed on the main set (offline rescore of the v3 answers, `pilot-v3-*.json`) and then run live on the held-out set.

The letter main-set figure is the rerun after one wording revision of two literacy patterns (`keyword_word`: "any other word, even one that starts with the right sound"; `other_sound`: "a held consonant such as mmm or nnn is a letter sound, not filler"). That revision was made after the held-out run, so the letter held-out figure (75/87) is no longer a clean held-out result. A fresh letter case set is owed when the patterns move into the domain.

## Residuals

- **`keyword_word` beyond the picture word (3/12).** "sun", "apple", "itch", "net" are named, but other words are not: "ant" for *a* reads as correct, while "snake", "insect" and "nose" fall just below the gate. Whether a word that starts with the right sound is wrong on `see_hear` is a question for the family's contract. For the stops the keyword is accepted (`acceptedFor`), so the answer is not obvious for vowels.
- **"nnn" for *p* read as no answer (3/3 unnamed)** even with the revised pattern: a held hum still looks like filler when it is not among the examples.
- **Bare single letters ("s", "p") are ambiguous** between the name and the sound in a transcript. The kind now reads them as correct. At wiring, the tutor's reply (the tutor heard the audio) is the evidence that settles them. It is not in the input yet and was not measured.
- The case writer set the miss precedence (`skipped_a_number` before `one_over`, `empty_count` before the off-by-n ids). Each family's domain owns that order at wiring.
