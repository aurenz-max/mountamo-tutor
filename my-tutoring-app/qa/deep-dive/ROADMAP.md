# Deep dive (agentic author) — roadmap

Owner of the agentic DeepDive (`service/core/deep-dive-agent/`) and generated displays
(`service/gen-display/`). Pull the top open item.

## Built 11-04/05 (committed cd673d56)

- `embed_primitive`: drawers as sections (menu from the catalog's affordances). Bench: 2 of 4 reading-grade lessons embed one.
- `add_see_also`: 2-4 links under a finished lesson, opened through the follow-up path (which can also embed drawers).
- Outline-first lessons: `plan_lesson.sections` (heading + key ideas); blocks carry `section` + `ideas`; code checks coverage (every idea taught, every check tests an idea taught above it, 2-4 blocks per section); reviewer names up to 2 missing essential ideas. Page shows section headings and a contents list.
- Generated displays pilot: kit (`sdkSource.ts`), compile + static checks, sandboxed page (no network, opaque origin), headless harness (probes + screenshots), `create_display` authoring loop with a vision judge, file library (`data/gen-display`), `use_display` / `request_display` in the agent, `GenDisplayBlock` iframe. One seed template (two lines meet). Smoke: `node scripts/gen-display-smoke.mjs`.
- 11-05: coordinate-graph choices shuffled in code (live probe: key at A/B/C/D 4/5/2/4 of 15). Deep dive agent choices were already shuffled (bench: 18/17/7/15 of 57).

- 11-05 DD-4 native math: `utils/mathText.ts` (`$...$` split, `mathIssues` check, `spokenMath` LaTeX to words, `repairMath`), kit `LuminaMathText` in every deep-dive block renderer, headings, contents, See also and the fill-blank slot; prose with math flows as plain paragraphs (the line-measuring renderers would split an expression). Agent: prompt rule + blocking check per block and per heading. Follow-up path (staged generator): rule in each brief + `repairMathDeep`. Tutor: scene, hear messages and the spoken key go through `spokenMath` (a LaTeX choice is keyed "negative 3"). Display kit: `Formula({ tex, display })`, KaTeX MathML inlined only in pages that use it (+270 KB). Evidence: bench `g8-systems` (`qa/deep-dive-bench/dd4-math-g8.json`): 50 expressions, 0 issues, $0.044; headless drive of that lesson in the tester: 3 sections, 42 typeset, 0 raw `$`, 0 page errors; `gen-display-smoke` formula probe passes.
- 11-05 DD-11 four display blocks: `chart`, `number-line`, `definition`, `passage` (types + `blocks/InsetBlock.tsx` over the knowledge-check inset renderers, with a tutor ask). Agent tools `write_chart|number_line|definition|passage` with build errors (2-12 points, pie 2-6 non-negative, line >= 3 points; number-line step splits the range into <= 20 parts, points and region in range; plain-text labels; attribution required except prose) and checks (definition must not use its own term; passage <= 120/200/300 words by grade; passages exempt from the sentence-length rule). Pre-readers get the number line only. Shared renderer fixes: number line end labels were clipped ("-6" read as "6") and the passage quote mark was clipped; definition text now typesets math. Evidence: bench `qa/deep-dive-bench/dd11-insets.json` (g4 railroad: definition + passage "Adapted from Harriet Tubman"; g5 climate: definition, agent chose a data table over a chart; g6 integers: number line A-D + definition, 104 expressions, 0 math issues; $0.19); headless drives of each new block, 0 page errors.
- 11-05 DD-12 `worked-example` block: problem, 2-6 steps (work + reason) revealed one at a time, answer at the end. At apply/analyze (`tierModes.workedTry`) code requires a try step: the student picks that step's line from the real one and three agent-named errors (code shuffles; graded item, spoken key is the spoken math); later steps stay hidden until it is settled, then the rest and the answer show at once (the shell closes a checked block until Next challenge, which first locked the remaining steps; caught in the drive). Agent: `write_worked_example`; build errors for step count, try step range, repeated lines. New check on every block: an all-numeric equation that is false ("$2(4) + 3 = 12$") blocks (`falseEquations`, mathjs via `tryEvaluateKatex`); 0 false alarms on 28 equations in earlier lessons. Evidence: bench `qa/deep-dive-bench/dd12-worked.json` (g7 two-step equations and g8 systems, both chose a worked example with a try step; distractors are real slips; $0.15); headless drive: wrong pick keeps steps hidden, shell Try again, right pick reveals all 4 steps + answer, 0 page errors.
- 11-05 DD-13 `process` (3-6 stages of a one-way process, arrows, tap a stage for the tutor) and `misconception` ("You might think" / "Actually" / why; not for pre-readers). Cycles are NOT a process: the first run (`dd13-process.json`, water cycle) embedded the catalog's `drawer-cycle-wheel`, which already does cycles better (asks what comes next), so the block was cut to sequences and the tool points loops at the cycle wheel. Evidence: `qa/deep-dive-bench/dd13-process-b.json` (g5 how a bill becomes a law: committee process + veto-override misconception, $0.03); headless render of both, 0 page errors.
